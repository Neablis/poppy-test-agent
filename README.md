# poppy-test-agent

Throwaway test Personal Agent identity for Poppy (Personal Agent Protocol)
conformance testing of caesura.today, generated by `allowfy-check keygen`.
Not a real agent and not a production allowlist entry.

`agent.json` and `jwks.json` are public by design: the company fetches them
to verify the test agent's signed assertions. The private key is NOT in this
repo; it lives only on the machine that runs the checks.
